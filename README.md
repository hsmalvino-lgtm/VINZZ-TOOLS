# VINZZ Tool

Cara Install di Termux:
1. `pkg install jq curl`
2. Download script: `curl -O https://raw.githubusercontent.com/USERNAME/VINZZ-Tool/main/VINZZ`
3. `chmod +x VINZZ`
4. `cp VINZZ $PREFIX/bin/VINZZ`
5. Jalanin: `VINZZ`

Jangan lupa ganti `API_KEY` di dalam script pake API Key Groq lo sendiri.
